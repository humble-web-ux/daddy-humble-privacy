DADDY HUMBLE Privacy Policy

Last Updated: October 25, 2026

1. Introduction

DADDY HUMBLE is a Discord bot that provides commands for Discord servers.

2. Information Collection

The bot does not intentionally store users' personal data permanently. It may process Discord user IDs, server IDs, and command inputs temporarily to execute commands.

3. Data Storage

The bot is not designed to maintain a database of users' personal information.

4. Data Sharing

The bot owner does not intentionally sell users' personal information.

5. Third-Party Services

The bot uses Discord. Please review the Discord Privacy Policy.

6. Changes

This policy may be updated if the bot's features or data practices change.

7. Contact

For questions, contact the owner of DADDY HUMBLE through Discord.
